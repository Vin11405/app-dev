# Need for Speed (2014)

![Need for Speed Movie Poster](https://upload.wikimedia.org/wikipedia/en/e/e3/Need_For_Speed_poster.jpg)

## About the Movie

**Need for Speed** is a 2014 action racing movie directed by *Scott Waugh*. The movie focuses on street racing, friendship, and revenge.

The main character, **Tobey Marshall**, is a skilled street racer and mechanic who participates in a dangerous cross-country race to prove himself.
